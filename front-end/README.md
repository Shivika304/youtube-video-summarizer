# YouTube Video Summarizer Frontend

A simple React frontend for processing YouTube videos into transcripts, summaries, and study notes.

## Student Project Features

- 🎥 YouTube video URL processing
- 📝 Transcript extraction
- ✨ AI-powered summaries
- 📚 Study notes generation
- 📱 Clean, simple design
- ⚡ Real-time video preview

## Getting Started

### What You Need

- Node.js (version 16 or higher)
- npm (comes with Node.js)

### How to Run

```bash
# Go to the frontend folder
cd front-end

# Install what we need
npm install

# Start the app
npm run dev
```

The app will open at `http://localhost:5173`

### Backend Setup

Make sure your Flask server is running on `http://localhost:8000` first!

## What We Use

- **React** - Makes the website interactive
- **TypeScript** - Helps catch mistakes
- **Vite** - Fast development server
- **Lucide Icons** - Pretty icons
- **Plain CSS** - Simple, clean styling

## How to Use

1. Start your Flask backend server
2. Start this frontend with `npm run dev`
3. Paste a YouTube URL
4. Click what you want (transcript, summary, or notes)
5. Wait for the magic to happen!
